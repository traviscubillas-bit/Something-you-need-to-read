About our project

Turning Ideas into Interactive Experiences Our project is a team portfolio website developed using HTML, CSS, and JavaScript. It introduces our team members, presents our goals, and showcases our skills in web development. We also created a Random Quote Generator that connects to an external API to display inspirational quotes. Through this project, we aim to improve our programming skills, explore API integration, and learn how to create a functional, user-friendly, and responsive website..

Random Quote Generator

Our app shows a new random quote every time the user clicks a button, along with the name of the author. The main goal is to give people a quick dose of inspiration in a clean and easy-to-use page.

  • "New Quote" button that fetches a fresh quote
  • Live data pulled from a public API using fetch()
  • Friendly error message when something goes wrong
  • Works on phones, tablets, and computers
