About the project:
VERBA is a random quote generator created as a midterm project. It shares
quotes from prominent and impactful people to encourage reflection and offer
meaningful perspectives.

API:
Name: DummyJSON Quotes API
Documentation: https://dummyjson.com/docs/quotes
Random quote endpoint: https://dummyjson.com/quotes/random

Technologies:
HTML, CSS, and JavaScript

Project files:
- index.html: Portfolio homepage with the project information and team.
- app.html: Random quote generator application.
- style.css: Shared responsive styles for the portfolio and application.
- script.js: Shared quote-fetching behavior utilized by the application.
- CubillasT.jpg, christianbuang.jpg, biso.jpg: Team member photos.

How to run locally:
1. Open the project folder in VS(Visual Studio) Code.
2. Start a local web server like the Live Server extension.
3. Open index.html for the portfolio or app.html for the quote generator.

Internet connection is required to get quotes from the DummyJSON API.
