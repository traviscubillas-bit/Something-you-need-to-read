About VERBA.

VERBA is a random quote generator built with HTML, CSS, and JavaScript for a midterm project. Its purpose is to inspire others through the words of prominent and impactful people, offering meaningful perspectives that encourage users to pause, reflect, and see things differently. With each new quote, VERBA aims to share words that resonate beyond the screen.

  • Fresh quotes from the DummyJSON Quotes API
  • Author attribution with every quote
  • Helpful feedback while a quote loads or if a request fails
  • Responsive layout for phones, tablets, and desktops
